# Map Module — Interactive Demo

Полноценная интерактивная демонстрация `@firec/map-module` с процедурной генерацией мира, управлением игроком, редактором тайлов и миникартой.

## Возможности

- 🌍 **5 генераторов мира**: Биомы (шум), Острова, Подземелье, Плоская карта, Шахматная
- 🎮 **Управление игроком**: WASD + коллизии
- 🔍 **Зум**: колесо мыши (от 0.15× до 3×)
- 📷 **Плавная камера** с интерполяцией
- 🗺️ **Миникарта** с отображением загруженных чанков
- 🎨 **Динамические визуалы**: анимация воды, пульсация факелов, вариации травы и деревьев
- ✏️ **Редактор тайлов**: ЛКМ — поставить, ПКМ — убрать
- 🔄 **Пересоздание мира** с новым seed
- 📊 **HUD**: FPS, координаты, чанк, тайл, LOD, статистика
- 📜 **Лог событий**: загрузка/выгрузка чанков
- ⚡ **LOD (Level of Detail)**: автоматическое упрощение при отдалении

## Запуск

```bash
cd demo

# Установить зависимости (модуль подключается из ../src через алиас)
npm install

# Запустить dev-сервер (автоматически откроет браузер)
npm run dev
```

## Управление

| Клавиша | Действие |
|---------|----------|
| `W` `A` `S` `D` | Движение игрока |
| `Колесо мыши` | Зум камеры |
| `ЛКМ` | Поставить выбранный тайл |
| `ПКМ` | Убрать тайл (поставить empty) |
| `R` | Создать новый мир (случайный seed) |
| `1`–`7` | Выбрать тайл (трава, вода, песок, камень, дерево, валун, цветок) |

## Панель настроек

Правая панель содержит:

- **Мир**: seed, выбор генератора, кнопка пересоздания
- **Параметры чанков**: размер чанка (8–32), размер тайла (16–64px), радиус загрузки (1–6)
- **Игрок**: скорость, коллизии, плавная камера
- **Редактор**: выбор тайла для размещения
- **Статистика**: загруженные чанки, тайлы на экране, FPS, время кадра
- **Лог событий**: события загрузки/выгрузки чанков

## Генераторы

### 🌍 Биомы (BiomeGenerator)
Многослойный шум для создания естественных биомов: глубокая вода, вода, песок, трава, лес, камень, снег. Деревья, камни и цветы добавляются вторым проходом.

### 🏝️ Острова (IslandGenerator)
Радиальное затухание + шум для генерации островов в океане. Каждый чанк может быть частью острова или океаном.

### 🏰 Подземелье (DungeonGenerator)
Комнаты, соединённые коридорами, с колоннами и факелами. Классический roguelike-данжен.

### 🟩 Плоская (FlatGenerator)
Простая плоская карта с травой и случайными деревьями.

### ♟️ Шахматная (CheckerboardGenerator)
Отладочная шахматная раскраска для проверки системы координат.

## Как это работает

1. **World** создаётся с выбранным генератором и параметрами чанков
2. **CanvasChunkRenderer** рендерит чанки с кэшированием в offscreen canvas
3. **ChunkViewManager** управляет frustum culling и LOD
4. Каждый кадр: обновление игрока → обновление камеры → world.update() → рендер → HUD
5. Редактирование тайлов через `world.setTileAt()` — кэш инвалидируется автоматически

## Примечания

- Модуль подключается напрямую из `../src/index.ts` через Vite-алиас — пересборка модуля не нужна
- Все генераторы детерминированы: одинаковый seed = одинаковый мир
- Динамические визуалы (вода, факелы) используют `TileVisualProvider` функции
